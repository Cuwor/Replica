# Реплика

Субтитры, видео и распределение ролей в одном окне.

- ASS, SSA, SRT, VTT, TXT, CSV и Google Docs.
- Назначение персонажей актёрам, включая совместные реплики.
- Правка времени, актёра и текста отдельной реплики.
- Добавление, удаление и сортировка реплик по началу.
- Просмотр видео с субтитрами.
- Экспорт ASS, SRT и CSV с сохранением актёров, текста и времени.
